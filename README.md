# Lufly Factory Showcase & Digital Catalog 🌿

A bespoke, ultra-fast European factory showcase & digital catalog website for **Lufly** (Sanitary Ceramics, Bathroom Architecture, & Washbasins).

## Features
- **Visual Identity**: Sustainable European luxury (Deep Emerald Green & Soft Sage).
- **Factory Credentials**: Showcasing European quality standards, eco-conscious ceramic engineering, and high export capacity.
- **Product Showcase**: 283 products categorized cleanly with instant SKU search and dimensions.
- **Digital Catalog**: Dedicated page to browse and download high-res PDF lookbooks and product catalogs.
- **Direct B2B Inquiries**: Quick WhatsApp and direct inquiry requests.

## Deployment
Configured for automated continuous deployment to **Vercel** with GitHub integration.
